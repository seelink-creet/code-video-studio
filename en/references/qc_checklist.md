# QC checklist
**Lookdev (before Gate 1):** key frames readable at phone size (360 px wide) · full-res crops of edges, thin lines, pixel edges, banding · matches STYLE.md; CJK fonts really contain CJK · motion test: no flicker, no jumps, easing and overshoot · re-check images under a new file name (some tools cache by path).

**Picture:** deterministic (same t → same frame); no jumps at chunk joins · contact sheet (every 0.5–1.5 s + last frame) viewed twice · strips of impacts, transitions, freezes · `qc_motion.py`: relative jumps only at intended hits, no stray black/white frames, no unexplained still >2.5 s, speed curve matches events · camera rules (forward only, no whip >3°/frame, bookend framing) · no hard `if t<X` layer cuts; no hand-off pop (plot displacement/speed) · text readable at final resolution, correct orientation (check glyph by glyph; mirrors/flips are common), no typos, URLs/brand names exactly as given · burst without white-out (≤0.07); no crushed blacks; no banding · safe area: keep key text out of the top/bottom ~10% and right ~12% on vertical platforms.

**Sound (measure instead of listening):** sound on frame 0; ending audible (check level curve) · hits within 1 frame of events (onset detection or same timeline) · music section entry on the agreed visual beat (±1 beat) · no glides: pitched SFX move ≤1 semitone within 300 ms (pyin), wobble ≤±0.5 st · no same-variant repeats; no knock/tap transition sounds; no level jumps within 50 ms of cuts · long slowed whooshes don't land inside near-silent holds · master after AAC: −14 LUFS (or agreed) ±1, true peak ≤ −1 dBTP.

**Delivery:** HD H.264 High, yuv420p, +faststart, bt709 tags, under the size limit · chat version 4–8 MB; integer scaling for pixel art · files play (ffprobe reads the duration; nothing truncated) · covers in two ratios; no spoiler titles · every music/SFX/font/text item has source + licence recorded; CC BY credits in the post; no NC/ND for commercial use; SA only if accepted · README re-render commands.
