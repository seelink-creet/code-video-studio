# hello-film · 10 秒完整示例（可选）

虚构的通用演示：墨点落下 → 落地挤压 → 近定格蓄力 → 炸成粒子 → 沿弧线聚成 “HELLO” → 安静定格。
用来验证环境、看清整条流水线，然后照着改成你自己的片子。

```
python3 run_all.py      # 一键：关键帧 → 渲染 → 音效 → 母带 → 质检 → 联系表 → 交付
```
产物都在 `out/`：`still_*.png`（关键帧）、`picture.mp4`（无声母版）、`sfx.wav`、`final.mp4`、`qc_motion.png`、`sheet.png`、`hello_HD.mp4`、`hello_chat.mp4`、`hello_cover*.png`。

演示了什么：
- `film.py` 里 `frame(T)` 是纯函数（种子 11），可任意跳帧、多进程分块渲染。
- `KEYS` 变速：落地后近定格（约 0.1×）→ 爆发 2.8× → 聚字时放慢；渲染 frame(τ(T))，不是复制帧；拖影随瞬时速度变长。
- 12 法则里的挤压拉伸、预备动作、弧线、慢入慢出、错开到达（避免齐步）、夸张（爆发初速度偏上、提亮 ≤0.07）。
- 同一份时间线（τ 事件）换算成输出时间后驱动音效：落地 thump、蓄力持续音（不滑音）、爆发碎裂 + whoosh、聚齐时 sparkle + chime。
- 母带 −14 LUFS、AAC 后真峰值 ≤ −1 dBTP；交付高清版、聊天版、封面。
