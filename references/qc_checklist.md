# 质检清单（QC）

## 样张阶段（闸门 1 之前，自己先查）
- [ ] 每张关键帧缩到手机尺寸（宽 360 px）仍能一眼读懂：主体、关键文字、关键色。
- [ ] 全分辨率裁切看细节：字边、细线、像素硬边、色带。
- [ ] 风格符合 STYLE.md（色板、字体、留白、署名位置）；中文字体真的含中文（缺字会显示方块）。
- [ ] 动测：无闪烁（种子固定）、无跳帧、风/水/镜头运动有缓动和过冲。
- [ ] 换个文件名再看图（有的工具按路径缓存图片）。

## 全片画面
- [ ] 确定性：同一 t 渲两次结果一致；分块渲染接缝处无跳变（查帧差）。
- [ ] 联系表（每 0.5–1.5 s 一格 + 最后一帧）完整看两遍：节奏、留白、每段是否有动作。
- [ ] 动作条：冲击、转场、定格前后每一帧。
- [ ] `qc_motion.py`：相对突变只出现在有意的冲击点；无意外黑/白帧；没有 >2.5 s 的无理由静止；变速曲线与事件线对得上。
- [ ] 镜头规则（如有）：只前进、朝向无甩镜（单帧转角 <3°）、bookend 构图一致。
- [ ] 图层没有 `if t<X` 硬切；物理交接无“抖一下”（画位移/速度曲线）。
- [ ] 文字：在最终分辨率可读，方向正确（逐字放大看，镜像/倒置常发生在透镜/背面），没有错别字，网址/品牌名与用户给的一致。
- [ ] 爆发不白屏（全局提亮 ≤0.07）；暗场不死黑；浅色渐变无色带。
- [ ] 安全区：竖屏上下约 10%、右侧约 12% 留给平台 UI，关键文字不放那里。

## 声音（你通常听不到，所以用测量代替耳朵）
- [ ] 第 0 帧有声音；结尾不轻到听不见（看电平曲线）。
- [ ] 卡点：事件时间与音效/音乐 onset 误差 ≤1 帧（onset 检测或从同一时间线生成）。
- [ ] 音乐段落入口落在约定的画面节拍上（±1 拍）。
- [ ] 无滑音：带音高的音效 300 ms 内音高变化 ≤1 半音（pyin 检测），抖动 ≤±0.5 半音。
- [ ] 同类音效没有连续用同一款；没有 knock/tap 式转场音效；切点前后 50 ms 无电平跳变。
- [ ] 长的减速 whoosh/呼吸声中段没有落进“近静音”段。
- [ ] 母带：AAC 编码后实测 −14 LUFS（或约定值）±1，真峰值 ≤ −1 dBTP。

## 交付
- [ ] 高清版：H.264 High、yuv420p、+faststart、色彩元数据 bt709；体积低于目标上限。
- [ ] 聊天版 4–8 MB 可直接发送；像素片选整数缩放。
- [ ] 文件完整可播放（ffprobe 能读出时长，未被中断写坏）。
- [ ] 封面两种比例；标题不剧透。
- [ ] 许可：每段音乐、音效、字体、文本都有来源与许可证记录；CC BY 署名写进发布文案；没有 NC/ND（商用时）或 SA（除非接受）。
- [ ] 源码可重渲（README 写明命令）。
