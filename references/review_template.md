# 自评模板（每次交给用户看之前填写）

> 原则：诚实、具体到秒、先看证据再下结论。证据 = 联系表、动作条、裁切、qc_motion 曲线、响度报告。不能确认的要写“无法确认”。

```
## 《片名》v{N} 自评
规格：{宽}×{高} {fps}fps {时长}s ｜ 高清 {MB} ／ 聊天版 {MB} ｜ 响度 {LUFS} / 真峰值 {dBTP}（AAC 后实测）

### 做得好的（最多 3 条）
1. {第几秒}：{什么}——{为什么有效，对应哪个原则：钩子/变速/文字在世界里/首尾呼应…}

### 不足（至少 2 条，按严重程度）
1. {第几秒}：{问题}——{证据：哪张图/哪条曲线}——{建议改法 + 预计工作量}

### 和需求的对照
- 时长/画幅/文字/网址/禁忌：{是否满足}
- 节拍表里的关键节拍是否都到位：{逐条}

### 我无法确认的
- 声音听感（我看的是电平、onset、音高检测）；手机外放效果；平台压缩后的样子。

### 下一步选项（给用户选）
A 定稿交付 ｜ B 修改上面第 {x,y} 条 ｜ C 换结尾/方向，出两版对比
```

## 常见自查问题
- 前 6 秒：第 0 帧有没有动作和声音？
- 中段：有没有超过 2.5 s 的匀速或静止？
- 文字：像“打在屏幕上”还是“长在世界里”？出现方式是否拖沓？
- 结尾：接得住高潮吗？首尾呼应了吗？意象和文本矛盾吗？
- 主体：到达时够不够大、够不够震撼？
- 廉价感来源：复制粘贴的群体、通用 GM 音色、循环同一和弦、通用 dissolve。
