# 节拍表模板

每个模板给：结构、时长占比、适合题材、必检项。拿到主题后套 1 个模板，写成 | 时间 | 画面 | 镜头/变速 | 声音 | 表给用户改。

## T1 载体物 + 意义文本 + 转化 + 余韵（写意诗意短片，20–30 s）
公式：一个日常可物理化的物体（水、烛、沙、雪、纸、烟）+ 与之形成隐喻的文本（优先公有领域：古诗词、过保护期作品）+ 一次不可逆的转化 + 留白结尾（关键字句 + 小小的署名印记）。
| 节拍 | 作用 | 占比 |
|---|---|---|
| ① 钩子/静 | 第 0 帧就在动，建立物体与质感，让观众“发现”字 | 15–25% |
| ② 扰动 | 预示变化（颤动、风起、预备动作） | 10–15% |
| ③ 事件 | 物理接管，最大动态，近定格→爆发 | 20–25% |
| ④ 转化 | 意义升华（例：字化成鸟、沙聚成字） | 20–30% |
| ⑤ 余韵 | 安静但不轻到手机外放听不见；关键句 + 署名印记 | 15–20% |
必检：文本与载体隐喻自洽；结尾不再塞大动作；关键句在最终分辨率下可读。

## T2 Bookend 首尾呼应（任何时长）
开头画面 = 结尾画面的同一机位/同一构图，但意义变了。示例（虚构）：开头一盏亮着的窗 → 结尾同一扇窗熄灯、窗台多了一盆花；或开头一个光点 → 结尾一切收回成同一个光点。
必检：用 `qc_motion.py --bookend 0 <结尾时刻>` 确认构图一致；改变的元素要一眼可见。

## T3 Stop-and-go 穿梭（30–60 s）
| 段 | 内容 | 变速 |
|---|---|---|
| 钩子 0–3 s | 起点场景，有动作 | 1× |
| 出发 | 镜头沿一条线索（例：一根线、一束光、一条河）冲出 | 1→3× |
| 站点 ×4–6 | 每站近停 0.6–1.5 s 读一个关键信息（移轴聚焦），再冲向下一站 | 0.1× ↔ 3× |
| 近定格 | 情绪最低点（例：一切逐渐冻结） | 0.05× |
| 爆发 | 3–4× 冲过剩余段落 | 3–4× |
| 归来/揭示 | 回到起点或拉远看到全貌 | 对数缓出 |
| 余韵 | 新生/定格/一个仍在动的小细节 | ≤1× |
必检：镜头只前进（QC 沿视线速度 ≥0），下一站提前可见；音乐段落入口落在“揭示”那一拍。

## T4 迷你世界三幕（40–60 s）
得宝 → 失去 → 夺回：
1. 日常 + 小喜剧（例：浇花时水壶漏水、打瞌睡）0–30%
2. 得到宝物（高举 + 闪光）
3. 危机：光被抽走/宝物被夺/黑夜，敌人或荆棘出现 30–60%
4. 蓄力（近定格聚光）→ 一击（约 0.25 s 的猛烈动作）→ 光回来 60–85%
5. 回收 + 小反转笑点 + 安静定格（例：角色走出画面、边缘碎成方块）85–100%
必检：前 6 秒有动作和声音；动作间隔不要等距；关键节拍略推近；笑点不靠文字解释。

## T5 宣传片（30–45 s，含 CTA）
钩子（最有特色的画面）→ 3–6 个卖点场景（每个 ≤5 s，一镜一个动作）→ 高潮动作 → 标题卡 + CTA（字幕/CTA 做成透明层，可不重渲直接改字）。
必检：所有文案集中在一个 config 文件；画面声明（是否动画演绎、是否用了真实截图）。

## T6 科普 / 讲解（20 s–3 min）
误区或问题钩子 → 概念 1 → 概念 2 → 反直觉点（近停）→ 总结一句 → 收尾回到开头意象。旁白先写，按 TTS 实测时长排画面。数据写来源。

## T7 作品集 / 混剪（45 s–3 min）
按音乐结构切段：开场重音（第 0 帧出声）→ A 段 → 高潮 → 近停 → 再冲 → 收尾回到开场意象 + 署名。所有 hit 来自同一份 timeline，cuecheck 误差目标 0 帧。

## T8 卡点 / 歌词 MV（按歌曲长度）
先分析一次音轨（节拍、小节、段落、能量、人声对齐），只信一个分析结果；高能段按拍切，舒缓段按乐句切；每句歌词一个镜头，转场有动机；第一版容易做成“花哨歌词视频”，歌词不是主角。须确认歌曲使用权。

## 写节拍表时的通用规则
- 每个镜头一个动作；不让场景静止太久（>2.5 s 没有明显运动就要有理由）。
- 结尾延续高潮的运动和逻辑，避免“只剩一屏大字”。
- 标出 2–3 个“近定格 → 猛冲”的位置，以及音乐必须对上的 1–2 个画面节拍。
