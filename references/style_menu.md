# 视觉风格菜单

✅＝已在多支成片中验证；🟡＝做过样张；⬜＝新建议（未验证）。每个风格给：气质、起始色板（可改）、字体建议（均为 SIL OFL 等可商用字体，使用前核对）、主要技术、注意事项、一个**虚构的示例**。

## ✅ 1. 写意文字（字即物质）
- 气质：宣纸、淡墨、留白、一点朱红；诗意、克制。
- 色板：纸 `#F2ECDE`，墨 `#1C1C20`（墨分五色：不透明度 .96/.82/.60/.34/.16），朱红 `#B02E22`。
- 字体：霞鹜文楷 LXGW WenKai、Noto Serif CJK；西文可选 OFL 手写体或铅字体。
- 技术：字形粒子缓存 + 目标吸引/群体/流体；纸纹、墨晕、轻泛光、颗粒、暗角。
- 注意：字松散、细看才读得出；大字作骨架、小字作肌理；不要把一个字拆成两半当部件；署名/印记固定在一个角落，全片不动。
- 示例（虚构）：“一封信的字被风吹起，飞成一群候鸟”。

## ✅ 2. 纸面像素小世界（留白 vignette）
- 气质：治愈、俏皮、程序感；“被照亮的一小块世界”。
- 色板：米白纸 `#EEE9DC`；主体色 3–4 阶；角色一个高饱和关键色；夜景纸底转深蓝，高光立住、暗部不压死。
- 字体：含中文的像素字体（如 Fusion Pixel，OFL）；注意很多像素字体**没有中文**。
- 技术：低分辨率网格（如 270×480）×4 最近邻；噪声场边界 → 有序抖动 → 2–12 px 多尺度方块散进纸白；多股风浪推动植被并带亮带。
- 注意：不要做成浮空岛泥土剖面；植被丛间留缝避免糊成竖条纹；角色极小时靠表情符号表达；聊天版选整数缩放。
- 示例（虚构）：“小人在雪地里堆雪人，雪人被风吹倒又自己站起来”。

## ✅ 3. 3D 穿梭 / 一镜到底
- 气质：震撼、宏大、速度感；也可做怀旧。
- 色板：深空（黑 + 金/紫/青光晕）；或纸边 + 某个年代的界面色。
- 技术：numpy 透视投影 + 平滑相机 + 时间重映射 + 快门拖影。
- 注意：只前进不倒退（QC 检查沿视线速度 ≥0）；下一站在远处提前可见；首尾同机位可做呼应；需要“有感觉但不清晰”的元素（如商标）可移轴虚化。
- 示例（虚构）：“镜头穿过一本书的每一页，最后从封底飞出”。

## ✅ 4. MG 动态图形 / 扁平矢量角色
- 气质：明快、信息密度高、俏皮。
- 色板：高明度底 + 2 个强调色 + 深色文字（例：`#F7F4EC` / `#E8453C` / `#2E86DE` / `#1E1E28`）。
- 技术：SVG 绑定角色 + cairosvg；PIL 动态排版；动作卡点音效。
- 示例（虚构）：“一颗咖啡豆讲解从种植到一杯咖啡”。

## ✅ 5. 音画同源（声音可视化）
- 气质：理性、优雅、数学美。色板：黑底 + 金/骨白/青。
- 技术：画面与声音由同一组振荡器/包络/FFT 驱动。
- 示例（虚构）：“每个音符在黑底上画出一条发光的弦”。

## ✅ 6. 静帧动态化
- 气质：电影感、留白、宽银幕遮幅。技术：Ken Burns、视差分层、颜色过渡。
- 注意：素材必须是用户自己的或可商用；有外部图像时不要说“全片代码生成”。
- 示例（虚构）：“用一年的旅行照片做成 30 秒回顾”。

## 🟡 7. 同一几何多种渲染（石刻光影 / 粒子 / 炭笔纸本）
- 技术：先算一次 G-buffer（法线/深度），换着色器出不同风格样张，便于让用户挑风格。

## 🟡 8. 古地图 / 手绘图纸
- 色板：羊皮纸 + 深棕墨 + 朱红标注。技术：线条生长、标注逐个出现。

## ⬜ 新风格建议（未验证，选用时先做 5 秒测试）
| 风格 | 一句话 | 建议技术 |
|---|---|---|
| 剪纸 / 立体书 | 平面纸片铰接、弹起，翻页=换场，配纸张拟音 | three.js 平片 + alpha 阴影，或 numpy 分块仿射 |
| 水彩 / 油画笔触 | 笔触采样底色、沿边缘对齐、轻微抖动 | p5.brush 或自写实例化笔触 |
| ASCII / 终端 | 字符亮度映射、扫描线、打字机 | 等宽字体字符网格 |
| 霓虹 / 赛博 | 加法光、bloom、色差、扫描线 | numpy 或 GLSL |
| 粘土 / 定格感 | 12 fps 姿势 + 轻微抖动 + 软阴影 | 2.5D + boil |
| 等距（isometric）小城 | 信息图、城市生长 | 等距投影 + 生长动画 |
| 极简几何 | 纯色块的节奏组合 | PIL / SVG |
| 数据新闻图表 | 数字故事、地图 | matplotlib 帧或自绘 |

## 通用美术规则
- 内部浮点合成，最后量化；浅色大面积渐变加细颗粒抖动防色带，需要时交付 10-bit。
- 线宽、字号、模糊半径、粒子尺寸按分辨率缩放。
- 不用纯黑纯白；发光单独一层加法合成。
- 颗粒用固定种子或在 ffmpeg 里统一加，避免闪烁。
